# D-0002 — Craftlight is an inventory tab

Accepted September 20, 2026 (September 21 UTC).

Rusty requested a tab in the normal E inventory, similar to Creative mode, instead
of a separate hotkey. The existing inventory receives an Inventory tab and a
Craftlight tab using vanilla Creative tab sprites and familiar chest/workbench
icons. The Craftlight page includes the same two tabs for direct return. No extra
keybinding is registered. D-0001's recipe, ingredient and station rules still apply.

Tabs follow the inventory's current position when the vanilla recipe book moves
it. The wider Craftlight page reserves space for tabs at small GUI sizes. Switching
pages uses normal server container cleanup to return cursor and crafting-grid
items. It does not replace the normal inventory, armor, offhand, recipe-book or
other mods' inventory controls. Creative retains its existing inventory behavior.

Real-client verification must use E and actual tab clicks, including return,
recipe-book shifts, GUI scaling, and ingredient preservation during transitions.
This approves development, not publication or deployment.
