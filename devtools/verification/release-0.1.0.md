# Craftlight 0.1.0

Adds a learned-recipe crafting tab to the E inventory. Click to craft once, Shift-click for up to one output stack, and right-click to preview. Uses normal ingredients and returned containers. Inventory-sized recipes work anywhere; larger recipes require a nearby crafting table. The chest tab returns to the normal inventory. No extra hotkey or recipe-viewer dependency.

Minecraft 1.21.1 · NeoForge 21.1.248 · Java 21. Install on both client and server.
